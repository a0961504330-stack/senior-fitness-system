# 樂齡運動智慧資料管理系統
Senior Fitness Data Management System

## 一、專案背景

目前於實習單位主要協助長者健身教室活動，以及進行行政資料與長者資料 Key in。

在實習過程中發現，長者相關資料、運動紀錄及體適能測驗資料需要進行大量輸入，部分基本資料也可能需要重複輸入。

因此希望利用學校所學的智慧科技與資訊技術，設計一套「樂齡運動智慧資料管理系統」，將課堂所學實際運用於實習場域中。

## 二、專案目的

本專案希望建立一個簡單且容易操作的資料管理網站。

第一次建立長者基本資料後，之後進行運動紀錄、體適能測驗或其他資料輸入時，只需要搜尋並選擇該名長者，即可自動帶入原有基本資料。

藉由系統減少重複 Key in 的時間，也降低人工輸入錯誤的可能，讓實習單位在長者資料管理及行政作業上更加方便。

## 三、使用對象

- 長者健身教室工作人員
- 運動指導員
- 行政人員
- 實習生

## 四、主要功能

1. 長者基本資料建立
2. 長者資料搜尋
3. 自動帶入長者基本資料
4. 長者運動紀錄登錄
5. 體適能測驗結果紀錄
6. 長者出席紀錄
7. 歷史資料查詢
8. 資料統計與圖表
9. AI 文字紀錄整理

## 五、系統操作概念

工作人員第一次建立長者基本資料後，系統會保存該名長者的資料。

之後若要新增運動或體適能紀錄，只需要搜尋長者姓名或編號，即可直接帶出原有資料，不需要每次重新輸入。

例如：

王○○ → 搜尋長者 → 自動帶入基本資料 → 輸入本次運動或測驗結果 → 儲存紀錄。

## 六、預期效益

- 減少重複 Key in 的時間
- 降低人工輸入資料錯誤
- 快速搜尋長者資料
- 保存長者歷史運動紀錄
- 比較不同時間的體適能測驗結果
- 方便工作人員進行資料整理
- 提升實習單位行政作業效率

## 八、未來規劃

## 十、系統操作流程

本系統主要提供長者基本資料管理、運動紀錄及體適能測試資料管理功能，預計操作流程如下：

1. 工作人員進入系統。
2. 搜尋長者姓名或編號。
3. 若長者資料不存在，先新增基本資料。
4. 系統自動帶入長者基本資料。
5. 工作人員輸入當日運動紀錄或體適能測試結果。
6. 系統將資料儲存至資料庫。
7. 工作人員可查詢長者的歷史運動紀錄。
8. 未來可透過統計圖表比較長者不同時期的運動表現。

## 十一、系統架構

本專題規劃採用網頁式系統架構，主要分成前端介面、後端程式、資料庫及版本管理四個部分。

### 1. 前端介面
- HTML：建立網頁基本架構。
- CSS：設計網頁外觀及排版。
- JavaScript：處理網頁互動功能。

### 2. 後端系統
- Python：處理資料新增、查詢、修改及儲存等功能。

### 3. 資料庫
- SQLite：儲存長者基本資料、運動紀錄及體適能測試結果。

### 4. 版本管理
- GitHub：保存專案文件、管理程式版本及提供老師檢視。

### 5. 未來擴充功能
- AI：協助整理長者運動紀錄。
- 統計圖表：呈現長者運動能力的變化趨勢。
